Project Overview

This project focuses on analyzing sales and revenue data using Microsoft Excel to understand business performance and generate meaningful insights.

Tools Used

• Microsoft Excel
• PivotTables
• PivotCharts
• Excel Formulas

Key Performance Indicators (KPIs)

• Total Sales
• Total Profit
• Total Orders
• Profit Margin

Analysis Performed

• Monthly Sales Analysis
• Monthly Profit Analysis
• Monthly Order Trend
• Region-wise Analysis
• Category-wise Analysis
• Product-wise Analysis

Data Preparation

• Data cleaning and formatting
• Missing value checking
• Duplicate value checking
• Data organization and preparation for analysis

Project Outcome

Developed an Excel dashboard to track key business metrics, analyze sales performance, and present business insights through visualizations.
